# Spec: calls/virtual-background
Efeitos visuais de plano de fundo na câmera do operador.

## Requirements
- O sistema deve fornecer opção de câmera sem efeitos (fundo real).
- O sistema deve fornecer opção de desfoque de fundo (*blur*).
- O sistema deve permitir escolher uma imagem estática corporativa como plano de fundo.
